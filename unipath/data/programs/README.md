# UniPath program data

`data/programDetails.ts` is the public program-data API used by the application routes.

The catalog is split into regional files only to keep the source maintainable. Program IDs must be stable and unique. Existing IDs should not be renamed after routes are published.

## Data rules

- Use official university, college, faculty, or program websites only.
- Prefer a specific official undergraduate program page when it is confidently known.
- If a specific page is uncertain, use an official program finder or admissions page rather than guessing a URL.
- Do not publish an exact competitive average or deadline unless it has been verified for the relevant admission cycle.
- Use `Varies — check official requirements` and `Check official requirements` when current values are not verified.
- Career items are examples of possible directions, not promises of employment.
- Keep colleges and polytechnics school-specific; do not copy program categories from another institution simply to fill space.
